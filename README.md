# Onze API

Backend do **Onze — Organizador de Pelada**.

## Stack

- Java 25
- Spring Boot 4.1.1
- Maven
- PostgreSQL 18
- Flyway
- Spring Security
- OpenAPI/Swagger

## Branches

- `master`: versão estável
- `development`: integração e validação
- `feature/*`: desenvolvimento por funcionalidade

## P0

Fundação técnica da API, incluindo banco, migrações, autenticação base, health check e CI.
